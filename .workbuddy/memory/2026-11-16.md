- 用 Delphi 11.3 完成了系统资源实时监控工具（CPU/内存/磁盘），纯 WinAPI+VCL 无第三方依赖。
- 项目路径：C:/Users/yls/Desktop/pdfview/系统资源监控
- 文件：ResourceMonitor.dpr/.dproj、MainForm.pas/.dfm、Monitor.Core.pas（采样引擎）、ChartUtils.pas（绘图）、README.md。
- 关键实现：CPU 每核用 NtQuerySystemInformation(8)；磁盘 IO 用 IOCTL_DISK_PERFORMANCE($00070020) 差值；进程用 Toolhelp32+GetProcessTimes；内存用 GlobalMemoryStatusEx+GetPerformanceInfo。
- 功能：六页签（总览/CPU/内存/磁盘/进程/设置）、托盘+气泡告警、阈值告警（CPU/内存/磁盘剩余）、CSV 日志、INI 设置、开机自启动。源码均带 UTF-8 BOM。
- 未在本机编译验证（环境无 Delphi 编译器），需用户在 IDE 中打开 dproj 编译。
- 修复编译错误：SampleDiskIo 局部变量 DI 与参数 Di 大小写不敏感冲突（重命名 DIo）；GetVolumeInformation 改为自导入 _GetVolumeInformationW；MainForm 补 System.Win.Registry。
- CPU 偏低问题：任务管理器(Win8+)用 % Processor Utility（含睿频频率加权），且 KernelTime 不含 DPC/中断。已改为 PDH 读取 '\Processor Information(_Total)\% Processor Utility' 作为总使用率，每核心补算 DpcTime/InterruptTime（offset 24/32），PDH 失败时回退经典口径。
- CPU 告警增强：告警消息中附带 CPU 占用最高的 3 个程序（TopCpuProcsText，过滤 System Idle Process，<0.1% 忽略），气泡/日志自动包含。
- 新增 CPU 温度：CpuTemp.pas 后台线程 TThermalThread（每5秒 WMI 查询 MSAcpi_ThermalZoneTemperature，取多热区最大值，开尔文/10 转摄氏度），MainForm 集成到总览/CPU页签标题/状态栏(6面板)/剪贴板/CSV快照，dpr+dproj+README 同步。温度不可用时显示"不可用"。
